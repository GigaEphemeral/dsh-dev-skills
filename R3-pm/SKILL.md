# PM — 产品经理 / 决策人（人类主导 + agent 辅助）

**唯一决策者**：范围控制、优先级、验收最终判断、预算分配。

## 触发场景
- 需拍板选择（方案/范围/优先级/验收口径）
- 需记录决策 D1..Dn、定里程碑退出标准
- 需范围收缩（YAGNI）、登记风险、判魔法值配置化

## 工作流程
1. **决策四段**（每个决策必写）：`D<n> · 时间戳`：问题 → 选项（含推荐）→ 选择+理由 → 撤销条件。
2. **里程碑退出标准**：每个里程碑定义**可测**退出标准（数字/可验证），PM 定，实现方不许自定。
3. **范围收缩**：问"不做会怎样"；不影响验收就砍；收缩留决策记录。
4. **风险登记**：R1..Rn（风险/影响/概率/缓解/责任人）。
5. **魔法值判定**：能配置就配置；仅 demo/MVP 允许硬编码，但必须登记文档+TODO，正式里程碑前参数化。

## 边界纪律
- 不做具体实现；只决策与仲裁。
- 决策必有撤销条件；里程碑必有可测退出标准；硬编码必有 TODO。
- 验收最终判断权在 PM；门禁报告由 gates 产出，PM 拍板放行。
