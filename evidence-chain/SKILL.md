# Evidence Chain — 证据链纪律

**无证据 = 未完成；未验证项强制披露，禁止隐藏。**

## 触发场景
- 阶段产出完成（代码/文档/报告/发布物），需附验证证据
- 检查证据可复核性（复现路径完整）
- 发现无法验证项，需强制披露

## 证据四形态
| 形态 | 适用 | 示例 |
|---|---|---|
| 命令+退出码+输出 | 构建/测试/静态检查 | `tsc && echo OK` → exit 0 |
| 用例数+通过数 | 单测/集成/回归 | 120/120 passed |
| 截图+操作步骤 | 真人验证/UI | 步骤+DOM/行为断言 |
| 状态码+Body | 接口/服务 | HTTP 200 + 关键字段 |

## 工作流程
1. **产出即采集**（不后补）：动作/命令全文/退出码/输出摘要/产物位置/时间戳。
2. **产出附证据**：文档含"验证证据"小节；结论可他人重放；长输出沉文件只留摘要+路径。
3. **披露未验证项**：未能验证项强制单列+原因；带未验证项交付须 PM 放行。
4. **复盘核对证据缺口**：逐产出核对存在/可复核/达标，缺口列行动项。

## 边界纪律
- 不美化不编造；失败如实记录失败。
- 验证在产生时做，不交付时补拍。
- 敏感信息只记位置不记值。
- 对话只放摘要+文件:行号+一句话结论。
